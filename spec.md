# Спецификация проекта: Распределённая система подачи филамента (Pico-MMU)

## 1. Общая архитектура системы

Система строится по принципу децентрализованной Master-Slave сети. Вместо одного сложного механического устройства используются автономные модули (боксы), объединённые общей шиной данных и питания.

| Компонент | Роль в системе | Расположение |
|---|---|---|
| Оркестратор (Master) | Координация слейвов, связь с Klipper, мониторинг финального датчика | Задняя стенка K1 (вместо штатного датчика филамента) |
| Сателлит (Slave Box) | Локальное управление 4-мя катушками (моторы, датчики, светодиоды) | Внешний стеллаж для пластика |
| Каскадный сплиттер | Механическое сведение трубок по схеме 4-в-1 | Уровень 1: внутри каждого бокса; Уровень 2: внутри Оркестратора |
| Шина (Backbone) | Передача 24V и данных RS485 | Стандартные патчкорды RJ45 (гирляндное подключение) |

---

## 2. Аппаратное обеспечение (Hardware)

### Узел Оркестратора (Master)

- **Микроконтроллер:** Raspberry Pi Pico 2 (RP2350)
- **Интерфейсы:**
  - Вход USB-C (для связи с хостом Klipper)
  - Выход RJ45 (старт шины к сателлитам)
  - Вход питания 24V (от БП принтера)
- **Датчик:** Микропереключатель (микрик) на выходе финального сплиттера
- **Сплиттер:** Печатный блок «4-в-1» (нейлон/SLA) с фитингами PC4-M6 на входах и выходе

### Узел Сателлита (Slave Box на 4 слота)

- **Микроконтроллер:** Raspberry Pi Pico 2 (RP2350)  
  Особенность: вывод USB-C на панель корпуса (через Panel Mount удлинитель) для локальной прошивки без разборки
- **Драйверы моторов:** 4× TMC2209 (подключение по UART для настройки тока и StallGuard)
- **Моторы:** 4× шаговый двигатель Nema 14 (или Nema 17)
- **Связь:** Микросхема трансивера RS485 (например, MAX485/SP485)
- **Питание:** Понижающий DC-DC преобразователь (24V → 5V) для питания логики от силовой шины
- **Периферия:**
  - 4× микропереключатель (входные датчики слотов)
  - Адресная светодиодная лента WS2812B (индикация локальных статусов)
  - Два порта RJ45 (IN и OUT) для сквозного подключения (Daisy Chain)

### Распиновка межблочной шины (Стандарт RJ45 / T568B)

| Пара | Пины | Назначение | Описание |
|---|---|---|---|
| Оранжевая | 1, 2 | +24V | Основное силовое питание моторов |
| Зелёная | 3, 6 | GND | Общая земля (силовая и логическая) |
| Синяя | 4, 5 | RS485 | Дифференциальная пара данных (A и B) |
| Коричневая | 7, 8 | GND / +24V | Дополнительные жилы для компенсации просадки напряжения |

## 3. Программное обеспечение (Software)

- **Язык разработки:** MicroPython
- **Асинхронность:** Активное использование библиотеки `uasyncio` для неблокирующей работы сети, моторов и датчиков
- **Управление шагами:** Использование сопроцессоров PIO (Programmable I/O) чипа RP2350 для аппаратной генерации импульсов Step, что полностью разгружает основной цикл интерпретатора Python
- **Протокол связи:** Полудуплексный RS485 (Master Polling). Рекомендуемая скорость: 115200 baud
- **Структура пакета данных (Payload):**

  ```
  [START_BYTE] [DEVICE_ID] [CMD] [LENGTH] [DATA...] [CRC16]
  ```

- **Многозадачность в Сателлите:**
  - **Ядро 0:** Обрабатывает шину RS485 и высокоуровневую логику стейт-машины слотов
  - **Ядро 1 / PIO:** Обслуживают драйверы TMC2209 и тайминги анимации WS2812B

## 4. Механика и стратегия синхронизации

### Механическое прохождение филамента

- **Геометрия:** Угол схождения внутренних каналов в сплиттерах — не более 15–20° для предотвращения заклинивания
- **Фиксация:** Крепление всех PTFE-трубок (от катушки до бокса, от бокса до Оркестратора) осуществляется исключительно через пневмофитинги (PC4-M10/M6) для исключения люфтов при ретрактах

### Алгоритм синхронизации при печати (Friction Compensation / Assist Mode)

Жёсткая пошаговая синхронизация мотора бокса и экструдера принтера **не используется** во избежание накопления ошибки и деформации прутка.

- **Фаза загрузки/выгрузки:** Мотор сателлита работает на полном рабочем токе (например, 0.8 А), активно толкая/вытягивая пруток до срабатывания датчика в сплиттере Оркестратора.
- **Фаза печати (Assist Mode):** По команде от Оркестратора сателлит программно снижает ток на TMC2209 (например, до 0.1–0.2 А). Мотор постоянно создаёт лёгкое усилие в сторону подачи, компенсируя трение в длинных трубках, но не выдавливая пластик самостоятельно. Основную тягу осуществляет экструдер принтера K1.
- **Механический буфер (опционально):** В конструкцию сателлита может быть интегрирован подпружиненный рычаг-компенсатор натяжения, срабатывание которого будет локально регулировать скорость или ток подающего мотора через Слейв-плату.
